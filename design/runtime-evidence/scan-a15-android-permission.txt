# —— A15 反例：拒绝授权后的横幅与退路 ——
$ adb shell pm revoke app.relay android.permission.CAMERA
# 注意：pm revoke 会**杀掉应用进程**。上一步的点击会落到当时的前台应用上，
# 必须先用 am start 把捎话拉回来再点。
$ adb shell am start -n app.relay/.app.MainActivity
# 节点页 → 右上 + → 「扫码配对」 → 「打开相机扫码」 → 再弹授权框 → 点「不允许」
# 扫码页原文（逐字）：
#   相机权限被拒绝，请在系统设置里开启后重试。        关闭
#   把对方的节点码放进框里
#   再试一次
#   扫不到？回节点页填地址
# 也就是说：失败有原因、有去处，不是一句「未知错误」。
$ adb shell pm grant app.relay android.permission.CAMERA
# 点「再试一次」→ 重新绑相机（attempt 递增，取景框重建），横幅保留到用户自己关掉。
