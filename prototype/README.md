# 捎话 (Tidings) UI 原型规范与设计稿说明

**手机 + 平板 + 桌面三端合一的单文件交互设计原型稿。**

设计稿采用单文件自含架构（HTML + CSS + SVG + JS），无任何外部网络运行时依赖，完整覆盖了移动端、平板与桌面端的全套界面状态、自适应布局断点与交互动效逻辑。

```text
prototype/
  relay.html          ← 交互原型稿（单文件，HTML + CSS + SVG + JS，无外部依赖）
  shoot-relay.py      ← 原型自动化截图脚本（Chrome headless，覆盖 116 帧设计状态）
  probe-relay.py      ← 盒模型与几何探针：逐屏量测盒模型，校验溢出 / 出框 / 字形截断
  check-contrast.mjs  ← 对比度审查工具：逐屏计算文字底色 WCAG 对比度（正文 ≥4.5:1、大字 ≥3:1）
  check-render.mjs    ← 静态渲染体检工具（Node.js vm 离线运行，检查未闭合标签与类名合法性）
  check-relay.sh      ← 语法与脚本合法性体检工具
  shots-manifest.json ← 截图状态清单与文件指纹
  README.md           ← 本文档
```

## 怎么看与本地预览

在本地启动任意静态 HTTP 服务即可预览原型：

```bash
cd prototype
python3 -m http.server 4173          # 浏览器打开 http://127.0.0.1:4173/relay.html
```

原型顶部提供形态切换与屏状态选择器：
- **形态（10 档）**：移动端外壳（手机 `phone`、平板竖屏 `tablet`、平板横屏 `tabland`、全宽 `full`）与桌面端外壳（紧凑 `compact`、中等 `medium`、扩展双栏 `expanded`、宽屏 `wide`、平板宿主 `tabhost`、独立设置窗口 `settings`）。切换形态时焦点自动平滑流转至语义相近的一屏。
- **深浅色主题**：实时切换浅色 / 深色模式。
- **字号档位**：支持标准字号与大字号（Large Font 2x）无障碍缩放。

### URL 控制参数

| 参数 | 取值范围 | 说明 |
|---|---|---|
| `size` | `phone` `tablet` `tabland` `full` `compact` `medium` `expanded` `wide` `tabhost` `settings` | 外壳形态，档位对齐 `DesktopLayout.kt` 的断点与移动端窗口尺寸 |
| `screen` | 屏 ID（见下表） | 直接进入指定屏状态 |
| `theme` | `dark` | 切换为深色主题 |
| `font` | `large` | 切换为大字号无障碍模式 |
| `insets` | `bad` | 复现测试安全区边距 |
| `av` | `initial` / `custom` / `<图标>.<底色>` | 头像档位（`initial` 为昵称首字，`custom` 为上传图片 WebP，数值为预设动物图标） |
| `actmore` | 整数 | 压缩头部直出操作按钮上限，触发折叠菜单「⋯」展开状态 |
| `gallery` | `1` | 启动画廊全景对比模式 |
| `bare` | `1` | 隐藏画框外部控制条（自动化截图专用） |

- **聊天与即时通讯**：私聊会话、私聊·切换会话、群聊会话、建群对话框、长按消息快捷操作菜单、群信息与成员列表。

- **文件柜与传输**：我的文件柜、对端文件柜、发送文件夹、接收文件夹、会话内历史搜索、历史搜索·日期筛选、屏幕协助历史卡片。
- **工作区与 Agent 协同**：工作区看板、工作区看板·空态、Agent 详情页、工作区详情页、工作区·会话详情流。
- **设置与系统配置**：设置首页、编辑个人资料、自定义头像（本地图片裁剪与 WebP）、连接与端口设置、通知与静音、外观与深色主题、能力声明清单、存储空间与数据清理、诊断与自检、自适应对比测试页。

### 桌面端（32 屏）

- **会话视图**：会话主界面（双栏布局）、会话内历史搜索居中弹窗、平板宿主·工具栏更多菜单、群聊主界面、建群对话框。

- **空状态与异常处理**：首次运行引导空态、未选中会话提示态、无文件空态、全局搜索无结果态。
- **传输与文件交互**：文件夹聚合卡片、入站断点续传卡片、文件柜管理面板、文件拖放悬停提示态。
- **扩展与高级工具**：全局全文检索面板、全局检索·空态、屏幕截图·框选提示框、屏幕截图·标注工具条、请求查看屏幕弹窗、同意并选择投屏屏幕（被看方）、观看远程屏幕视窗（查看方）。
- **设置与桌面系统集成**：设置视窗·身份与连接、设置视窗·存储与数据、设置视窗·桌面环境配置、中文输入法（IME）自检视窗、系统托盘菜单、表情选择浮层面板。

## 核心设计规范与交互纪律

### 1. 不设骨架加载态
本产品交互遵循**即时呈现与确定性状态**原则：不使用骨架屏（Skeleton）、闪烁微光（Shimmer）或居中转圈占位器。所有视图在数据加载完成前均呈现清晰明确的空态或基础布局骨架，数据到达后自然渲染，避免无意义的界面抖动。

### 2. 视觉尺寸与点击命中尺寸分离
触控热区必须严格满足无障碍触控指标（最小 44×44 或 48×48 dp）：
- 当视觉图标较小（如 16dp / 22dp）时，外部容器或点击靶区通过外边距或内边距补齐至标准触控尺寸。
- 文本按钮与浮层菜单必须具备明确的点击按压与 Hover 反馈态。

### 3. 输入区与工具栏体系
- **移动端输入栏**：采用单行紧凑布局，支持表情展开与「+」号抽屉面板，右侧常驻发送按钮与文本字节计数。
- **桌面端输入区**：采用浮起卡片结构，具备顶部高度拖拽把手、多行自适应输入框、能力工具栏（表情、PK、窗口震动、截图、图片、文件、文件夹及历史搜索）与底栏提示。
- **禁态语义反馈**：按钮不可用时提供 Tooltip 或上下文提示告知原因（例如：单聊方可使用窗口震动、群成员离线时置灰图片/文件发送）。

### 4. 自适应响应式断点体系
桌面端布局根据窗口宽度分为四档断点：
- **Compact（< 600dp）**：单栏布局，底部导航栏。
- **Medium（600dp ~ 840dp）**：单栏内容区 + 64dp 紧凑左侧导航 Rail。
- **Expanded（840dp ~ 1200dp）**：双栏布局，左侧会话/节点导航列表，右侧独立工作内容区。
- **Wide（≥ 1200dp）**：宽屏多栏布局，右侧支持常驻抽屉面板与展开详情。

### 5. 头像与身份识别规范
- **预设图标模式**：20 款动物表情符号 × 10 档精心调校的背景色（均满足 WCAG 4.5:1 正文对比度标准）。
- **首字头像模式**：根据昵称字符哈希自动分配背景色，居中显示首个汉字或首字母。
- **自定义图片模式（av1）**：支持用户选择本地图片，客户端就地裁剪为 192×192 正方形并导出 WebP 格式（≤ 32 KiB），计算 SHA-256 哈希值写入 Profile，局域网对端按需拉取。

### 6. 工作区与 Agent 协同模型
- **层级映射**：统一映射为四层实体：`节点 (设备) → Agent → 工作区 → 会话`。
- **状态呈现**：会话行清晰标明运行状态（运行中、空闲、等待审批），待办审批事项在工作区看板与会话头部以醒目角标提示。
